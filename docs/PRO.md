## Pro Features Preview

### Admin Dashboard (Filament)

A beautiful admin panel to manage commissions without code:

- View all commission plans and tiers
- Track earnings by agent, period, status
- Approve and process payouts
- Generate reports
- Manage clawbacks

### Advanced Reporting

- Commission trends over time
- Top earners leaderboard
- Plan performance comparison
- Payout forecasting
- Revenue attribution

### Configurable Currency

Set your preferred currency system-wide:

- 40+ currency symbols supported (USD, EUR, GBP, NGN, etc.)
- Clean symbol display (₦, $, €, £)
- Single currency mode for consistency
